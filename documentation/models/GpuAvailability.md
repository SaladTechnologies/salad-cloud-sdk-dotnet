# GpuAvailability

**Properties**

| Name               | Type | Required | Description                             |
| :----------------- | :--- | :------- | :-------------------------------------- |
| AvailableGpuBatch  | long | ❌       | The number of available GPU batches     |
| AvailableGpuLow    | long | ❌       | The number of available low-end GPUs    |
| AvailableGpuMedium | long | ❌       | The number of available medium-end GPUs |
| AvailableGpuHigh   | long | ❌       | The number of available high-end GPUs   |
| OnCallGpu          | long | ❌       | The number of on-call GPUs available    |
